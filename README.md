# Brolls — Vietnamese Rolling Broth Website

Responsive static website for Brolls in Olongapo City.

## Files
- `index.html` — page content and SEO/schema metadata
- `styles.css` — complete responsive design
- `script.js` — mobile navigation and dynamic footer year
- `assets/favicon.svg` — favicon

## Deploy to GitHub Pages
1. Create a new GitHub repository.
2. Upload everything in this folder to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.

## Before publishing
Replace generic licensed Vietnamese-food photography with Brolls' own product/interior photos for the strongest brand match.
Verify current opening hours, menu prices and delivery links before using the site as the official business site.
